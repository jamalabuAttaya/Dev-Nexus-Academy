# Dev Nexus Academy 1.1.0

## Product

- Unified Dev Nexus logo, favicon, social card, Apple touch icon, and installable-app icons.
- Expanded the catalog from 13 to 20 disciplines and from 28 to 37 curated resources.
- Added about, learner account, FAQ, contact, privacy, terms, content policy, and accessibility pages.
- Added production metadata, sitemap, manifest, security headers, loading, and not-found states.

## Deployment

- Added Vercel configuration and production environment templates.
- Added a production Docker image for Laravel.
- Added GitHub Actions, Dependabot, issue forms, and a pull request checklist.
- Added a complete manual GitHub and Vercel deployment guide.

## Backend

- Added idempotent seeders with 12 internal courses and 72 lessons.
- Added framework configuration for authentication, sessions, caching, logging, queues, hashing, and storage.
- Added tests for health, authentication, course visibility, enrollment, and progress.
- Added separate API and authentication rate limits plus production security headers.
